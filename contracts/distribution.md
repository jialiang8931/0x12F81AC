# Distribution contract

本 repository 的根目錄就是一個完整 skill package。`SKILL.md` front matter 的名稱固定為 `project-arch-init`，所有引用資源都必須留在 repository 內，且不得使用 symlink 逃出 package。

GitHub 發佈分支為 `main`。官方 installer 應能以 repository `jialiang8931/0x12F81AC`、path `.`、name `project-arch-init` 安裝。自然語言「請幫我安裝 jialiang8931/0x12F81AC 技能」應解析為同一來源。

安裝只代表 skill 可被發現，不代表任何目標專案已通過 `docs/init.md` gate，也不授權自動寫檔。
