# Read-only assessment

依序盤點：

1. `docs/init.md` 的 business boundary。
2. 既有 `AGENTS.md`、contracts、tasks 與局部規則。
3. 語言、service、entrypoint、資料與 external system。
4. Docker、CI、部署、Terraform、環境變數與 secret 路徑。
5. 測試分層、fixture、產物、暫存檔與 ignored files。
6. Git branch 現況與使用者未提交變更。

只做唯讀命令。既有程式與輸出是 evidence；只有經使用者核准的 business document 與 contract 才是規則。盤點結果要區分「已知、推論、未知」。
